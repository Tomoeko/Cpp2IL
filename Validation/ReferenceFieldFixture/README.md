# Reference-field read control

Build this neutral fixture with Unity 2021.3.35f1 Windows x64 Release IL2CPP. The methods read string or object fields directly or through one reference field. The harness checks returned value and reference identity for nonempty, empty, boxed and null values, plus null receivers at both levels. Array fields before and after each read target exercise unchanged layout when array type wrappers are rematerialized. Separate short-offset string reads exercise native bodies folded with other managed methods; their own signatures and field layout must still be proved. Derived owners add fields after the inherited storage and exercise the same reads to test base-field identity and layout.
