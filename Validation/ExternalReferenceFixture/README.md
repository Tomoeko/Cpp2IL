# External reference kinds

This synthetic fixture declares fields from an embedded package assembly definition
and a precompiled managed plug-in. Its one authored method has a simple arithmetic
body so the source-project reference classification can be tested independently of
new native recovery shapes.

The plug-in file name matches its managed assembly identity, as required by this
fixture's exact Windows IL2CPP rebuild. A separate controlled negative run with a
different file name compiled in the editor but failed Unity's native build during
assembly resolution.

The package and plug-in are synthetic project dependencies. The round trip also
supplies their compiled assemblies as explicit managed reference inputs and supplies
an explicit reference-kind map. These auxiliary inputs are recorded separately from
the selected assembly's player binary and metadata. Editor compilation, native
building and field reflection check that the generated assembly resolves both kinds.
