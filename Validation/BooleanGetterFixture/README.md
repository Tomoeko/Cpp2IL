# Instance Boolean getter fixture

Two ordinary sealed classes each expose a Boolean field and a method that returns it. The fields occupy the same position in their respective class layouts, allowing the exact Release player to expose a shared native body if its linker folds identical functions. A neighboring integer field detects unintended writes.

The independent `boolean-getter` driver checks both Boolean values, signed integer neighbors, unchanged state and null receivers in the Windows editor and player. The four selected methods include the two implicit constructors. Native code, source and behavioral claims require separate validation receipts; this fixture alone proves none of them.
